#### 🛡️ CerberusAI — an AI SOC analyst that investigates alerts on its own
**[github.com/justinbarrow30/cerberus-ai →](https://github.com/justinbarrow30/cerberus-ai)**

An open-source, read-only agentic SOC analyst. Point it at a SIEM and it investigates each alert
autonomously — querying the SIEM, learning what is normal for the network, and returning an
auto-close / escalate verdict with plain-English evidence. A self-growing memory learns the
network's topology and per-asset baselines, so it catches lateral movement a static rule would
miss — and it stays explainable (deterministic statistics plus a graph, no black box).

[![CerberusAI console](https://raw.githubusercontent.com/justinbarrow30/cerberus-ai/main/docs/console.png)](https://github.com/justinbarrow30/cerberus-ai)

Python · FastAPI · Pydantic structured outputs · LiteLLM (bring-your-own-LLM) · Model Context
Protocol · SQLite memory · Docker.
